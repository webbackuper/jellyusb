Vérification avant lecture

Si le support USB ou le fichier est absent, la lecture est bloquée et le client affiche un message.
Le MediaID est le nom du dossier qui suit ce chemin (ex. /mnt/usb/MOVIES03/...).
Variables : {title} (titre), {mediaId} (nom du support), {path} (chemin du fichier).
Android TV coupe ses messages après deux lignes : gardez le MediaID au début.
jellyfin-web affiche toujours sa propre fenêtre d'erreur quand une lecture est refusée. La première option ouvre le message JellyUSB par-dessus.
Pour que le message apparaisse après l'éventuel toast d'erreur de l'application.
