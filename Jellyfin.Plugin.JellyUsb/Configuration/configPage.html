Essentiel

Si le support USB ou le fichier est absent, la lecture est bloquée et le client affiche un message.
Le MediaID est le nom du dossier qui suit ce chemin (ex. /mnt/usb/MOVIES03/...).
Une première ligne est ajoutée au résumé, seulement dans ce que reçoit la TV : rien n'est enregistré. Markdown accepté, variable {mediaId}.
Android TV coupe ses messages après deux lignes : gardez le MediaID au début.
L'application Android TV reste sinon sur un écran noir jusqu'à ce qu'on appuie sur Retour.
Réglages avancés

Les valeurs par défaut conviennent dans la plupart des cas.

Textes des messages

Variables : {title} (titre), {mediaId} (nom du support), {path} (chemin du fichier).
jellyfin-web affiche toujours sa propre fenêtre d'erreur quand une lecture est refusée. La première option ouvre le message JellyUSB par-dessus.
Pour que le message apparaisse après l'éventuel toast d'erreur de l'application.

Interface web

Ajouté à la volée à index.html (les fichiers de Jellyfin ne sont pas modifiés). Rechargez la page après un changement.
Une ligne par support USB, avec son image de fond ; un clic sur un support affiche tous ses films.
Ouvre la vue par MediaID de la première bibliothèque de films qui a des supports USB.
